Für Vereins-Postfächer

Mail-Signatur

Hier baust du dir die Vereins-Signatur. Felder ausfüllen, kopieren, in dein Mail-Programm einfügen. So sehen alle Mails vom Verein gleich aus.

Leer lassen, wenn du keins hast.

Leer lassen, dann fällt die Zeile weg.

Vorschau

Signatur kopieren passt für Outlook, Gmail und Apple Mail am Mac. Nur Text nimmst du am Handy. HTML-Code brauchst du nur für Thunderbird.

So fügst du sie ein

Outlook am Windows-PC (klassisch)
  1. Oben „Signatur kopieren“ drücken.
  2. In Outlook: Datei → Optionen → E-Mail → Signaturen…
  3. Neu klicken, Namen eingeben (z. B. „SC 1911“), OK.
  4. Ins große Feld klicken und Strg + V drücken.
  5. Rechts oben das Vereins-Konto wählen. Bei Neue Nachrichten und Antworten/Weiterleitungen die neue Signatur einstellen.
  6. OK drücken.
Neues Outlook und Outlook im Browser
  1. Oben „Signatur kopieren“ drücken.
  2. In Outlook oben rechts auf das Zahnrad (Einstellungen) klicken.
  3. Konten → Signaturen → + Neue Signatur.
  4. Namen eingeben, ins Feld klicken, Strg + V (am Mac ⌘ + V).
  5. Darunter die Signatur für neue Nachrichten und Antworten auswählen.
  6. Speichern.
iPhone und iPad (Mail-App)
  1. Diese Seite am iPhone öffnen und „Nur Text kopieren“ drücken.
  2. Einstellungen → Apps → Mail → Signatur. Bei älteren iPhones: Einstellungen → Mail → Signatur.
  3. Bei mehreren Konten Pro Account wählen.
  4. Den alten Text („Von meinem iPhone gesendet“) löschen.
  5. Ins Feld tippen, lange drücken, Einsetzen.
  6. Oben links zurück. Es ist sofort gespeichert.
Outlook-App am Handy
  1. „Nur Text kopieren“ drücken.
  2. In der Outlook-App oben links auf dein Bild → Zahnrad.
  3. Signatur antippen, alten Text löschen, lange drücken, Einfügen.
  4. Zurück. Es ist gespeichert.
Apple Mail am Mac
  1. Oben „Signatur kopieren“ drücken (mit Safari oder Chrome).
  2. In Mail: Mail → Einstellungen → Signaturen.
  3. Links das Vereins-Konto wählen, unten auf + klicken.
  4. Rechts den Beispieltext löschen und ⌘ + V drücken.
  5. Den Haken bei Immer meine Standardschrift verwenden entfernen, sonst geht die Formatierung verloren.
  6. Fenster schließen.
Thunderbird
  1. Oben „HTML-Code kopieren“ drücken.
  2. In Thunderbird: ≡ → Konten-Einstellungen → links auf die Vereins-Adresse klicken.
  3. Den Haken bei Stattdessen HTML verwenden setzen.
  4. Ins Feld Signaturtext klicken und Strg + V drücken.
  5. Fertig. Thunderbird speichert von selbst.
Gmail (im Browser)
  1. Oben „Signatur kopieren“ drücken.
  2. In Gmail: Zahnrad → Alle Einstellungen aufrufen → Reiter Allgemein.
  3. Bis Signatur scrollen, + Neu erstellen, Namen eingeben.
  4. Ins Feld klicken, Strg + V.
  5. Darunter die Signatur als Standard für neue Mails und Antworten wählen.
  6. Ganz unten Änderungen speichern.
Android (Gmail-App, Samsung-Mail)
  1. „Nur Text kopieren“ drücken.
  2. Gmail-App: ≡ → Einstellungen → Vereins-Konto → Mobile Signatur.
    Samsung-Mail: ≡ → Zahnrad → Vereins-Konto → Signatur.
  3. Lange ins Feld drücken, Einfügen, OK.

Datenschutz: Was du hier eintippst, bleibt in deinem Browser. Nichts wird an den Verein oder einen Server geschickt.
