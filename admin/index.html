Anmelden

Beiträge werden direkt im GitHub-Repository der Seite gespeichert. Zum Anmelden brauchst du einen persönlichen Zugangsschlüssel von GitHub.

So bekommst du einen Zugangsschlüssel
  1. Bei GitHub anmelden (das Konto braucht Schreibrechte für Tecko1985/sch-website).
  2. Neuen „Fine-grained token“ anlegen.
  3. Name z. B. „SCH Redaktion“, Ablauf nach Wunsch.
  4. Bei Repository access „Only select repositories“ und sch-website wählen.
  5. Bei Permissions → Repository permissions „Contents“ auf Read and write stellen.
  6. „Generate token“ klicken und den Schlüssel hier einfügen.

Der Schlüssel bleibt in deinem Browser und geht nur an GitHub. Auf fremden Geräten „angemeldet bleiben“ nicht anhaken.
